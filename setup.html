// Setup Guide

Up and running
in 2 minutes.

Follow the steps below. Click each step to expand it. You'll never think about recruiter spam again.

01 —
Open the Marketplace listing
Find the add-on on Google Workspace Marketplace and click Install.
+

Go to the Google Workspace Marketplace listing for Recruiter Spam Filter. Click the blue Install button in the top right.

// Google Workspace Marketplace — click Install
// Make sure you're signed in
Use the Google account with the Gmail inbox you want to filter.
02 —
Get ready to install
Confirm the permission request to proceed.
+

A dialog will appear asking for permission to start installing. Click Continue.

// Click Continue to proceed
03 —
Dismiss the unverified app warning
Google shows this for all apps pending OAuth verification. It's safe to continue.
+

You'll see a screen saying "Google hasn't verified this app." This is a standard notice for apps still going through Google's verification process — not a sign anything is wrong.

// Click Continue to proceed — verification is in progress
// Why does this appear?
Google requires OAuth verification for apps that request Gmail access. We've submitted for verification. Until it's approved, this warning appears. Click Continue to proceed.
04 —
Allow Gmail access
Grant the permissions needed to read, label, and archive emails.
+

Google will show you exactly what the add-on can access. All permissions are required for the add-on to work. Click Allow.

// All permissions are needed — nothing extra is requested
Run as a Gmail add-on — displays the sidebar UI
Read & compose emails — needed to scan and classify
Connect to external service — sends subject/body to AI classifier
Run when not present — enables the hourly background scan
05 —
Installation confirmed
The add-on has been added to your Gmail sidebar.
+

You'll see a confirmation screen. Click Done, then open Gmail.

// Add-on successfully installed — click Done and open Gmail
06 —
Open the sidebar and activate
Click the add-on icon in Gmail's right panel, then hit Activate.
+

In Gmail, look for the Recruiter Spam Filter icon in the right sidebar. Click it to open the panel, then click the Activate button at the bottom.

// Click Activate — this schedules the hourly background scan
// Can't find the icon?
Click the + at the bottom of Gmail's right sidebar to browse installed add-ons and pin it.
07 —
You're live — hit Run Now to test
The add-on is active. Trigger your first scan manually to see it work.
+

After activating, the sidebar shows your status and stats. Hit Run Now to trigger an immediate scan — you'll see a toast showing how many recruiter emails were archived.

// Active status confirmed — Run Now to trigger your first scan
// From here, everything is automatic

Every hour: inbox scanned automatically
Recruiter emails: labeled _RecruiterSpam + archived
Everything else: never touched
Missed something? check the _RecruiterSpam label anytime
// Heads up — reauthorization
While the app is pending Google verification, you may need to re-authorize every ~7 days. We're working on getting verified to remove this step permanently.
